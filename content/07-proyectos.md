## Plantilla para casos de éxito (para fichas individuales de proyecto)

| Campo | Contenido |
|---|---|
| Titular | Tecnología + reto resuelto + resultado o hito alcanzado. |
| Ficha | Ubicación general, tecnología, potencia, duración BESS, tensión, año y estado. |
| Necesidad del cliente | Decisión, bloqueo o riesgo que debía resolverse. |
| Alcance Capturam | Trabajos ejecutados, entregables y coordinación asumida. |
| Complejidad | Condicionantes de red, terreno, medio ambiente, plazo o administración. |
| Solución | Criterios técnicos y secuencia de trabajo, sin información confidencial. |
| Resultado | Hito verificable: solicitud, autorización, RtB, PES, optimización o decisión. |
| Evidencias | Fotografía propia, plano anonimizado, esquema, cronología y testimonio autorizado. |

Ejemplo de titular: *«Diseño y tramitación de una instalación híbrida FV + BESS de 5 MW mediante AC coupling.»*

**Regla editorial:** no convertir la lista de referencias en una suma de logotipos. Cada caso debe explicar el reto, el alcance de Capturam y un resultado verificable. Si el cliente o el proyecto no puede citarse, usar una ficha anonimizada y mantener la magnitud técnica.
